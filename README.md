# QQ 聊天机器人 · 独立版

把 QQ 变成一个**有角色、会打字、会发语音**的 AI 聊天机器人。

自带控制面板、角色包与日语语音，**不依赖 DeepSeek Harness**。
QQ 登录需要另外装一个免费的网关（SnowLuma，两分钟，见[准备工作](#准备工作这些东西从哪来)第 0 步）。
下载解压，双击 `QQ聊天机器人.exe`，在面板里填几项配置，就能开始聊。

> 界面是网页做的（`http://127.0.0.1:3199`），用系统自带的 Edge 以「应用模式」打开，
> 看起来就是一个普通桌面窗口，没有地址栏。

## 它是什么 / 不是什么

**是什么**

- 一个跑在你电脑上的 QQ 机器人：你把 QQ 小号登进去，它在群里/私聊里按角色设定说话。
- 支持多角色（角色卡 + 角色包）、日语 + 中文字幕、Fish Audio 语音、静默时段、主动搭话、黑话词库、表情包。
- 模型可以接**任何 OpenAI 兼容接口**（DeepSeek 官方、硅基流动、自建中转等）。

**不是什么**

- 不是「挂在云上的服务」，它必须跑在一台开着的电脑上（Windows）。
- 不需要你有 DeepSeek Harness，那只是另一种后端选项。
- 角色卡不是官方授权内容，见[二次创作声明](#角色包与二次创作声明)。

## 功能

| 能力 | 说明 |
| --- | --- |
| 多角色 | 每个角色一张角色卡（`.md`）+ 一个角色包（`.pack.json`：音色、别名、注音、世界观名） |
| 日语 + 中文字幕 | 每段日语下面紧跟中文字幕，可开关 |
| 语音 | Fish Audio TTS，没有音色的角色只打字不发语音 |
| 静默时段 | 分「工作日」和「周末与法定节假日」两套时间，静默期只有被 @ 或引用才回应 |
| 主动搭话 | 按概率在群里起话头，有每日上限、夜间不打扰 |
| 黑话词库 | 群友黑话自动学习/手动维护，注入对话 |
| 表情包 | 收藏、发送、按场景挑 |
| 控制面板 | 启停、状态、密钥、白名单、角色包、静默时间、日志，都在一个窗口里 |
| 两种后端 | `standalone`（直连模型 API，默认）/ `dsh`（接 DeepSeek Harness） |

## 目录结构

```
qq-bot\
├─ QQ聊天机器人.exe        双击它（本仓库是源码，exe 由 npm run build 生成）
├─ node.exe                运行时（发布包里自带，源码仓库不含）
├─ start.bat               备用入口：带控制台窗口，方便看报错
├─ setup.bat               同上（历史入口）
├─ config.json             你的配置（发布包里没有，第一次启动生成模板）
├─ config.example.json     配置模板（全部字段的默认值与注释性说明）
├─ app\                    控制面板
│  ├─ ui.mjs               面板服务（端口 3199，只监听 127.0.0.1）
│  ├─ ui.html              面板页面
│  ├─ setup.mjs            配置向导（命令行版）
│  └─ launcher.cs          exe 的源码（C#，WinForms，仅用于拉起面板）
├─ src\                    桥接主程序
│  ├─ launch.mjs           启动入口：检查配置 → 起网关 → 起机器人
│  ├─ bridge.js            核心：QQ 消息 ↔ 模型 ↔ QQ
│  ├─ backend\             后端抽象（standalone 直连 / dsh）
│  ├─ quiet-hours.mjs      静默时段
│  ├─ tts-fish.mjs         Fish Audio 语音合成
│  ├─ role-card.js         角色卡解析
│  └─ mcp-*.js             工具（QQ 操作、联网搜索）
├─ roles\                  角色卡 + 角色包
├─ resources\prompts\      系统提示词（由角色卡与规则生成）
├─ public\console.html     本地管理控制台（端口 3101，面板内嵌的就是它）
├─ snowluma\               QQ 网关（**需要自己下载**，见准备工作第 0 步；本仓库不含）
├─ world.json              世界观资料（角色/事务所/背景）
└─ state\                  运行时状态：日志、会话、表情缓存、token
```

## 准备工作：这些东西从哪来

开始之前，需要准备这些东西。前两个是必须的，后面是可选。

### 0. 下载 QQ 网关（必须，两分钟）相关内容请参考[视频](https://www.bilibili.com/video/BV1ss8R6zERG/?spm_id_from=333.40164.0.0&vd_source=4f74b8840ccc61920140f59da178856b)的部分操作

本程序**不自带**网关：SnowLuma 是另一个独立项目，有它自己的许可（而且明确不允许被并进第三方安装包）。
所以这一步要你自己下，下完放到程序目录里就行。

1. 打开 <https://github.com/SnowLuma/SnowLuma>，进右侧 **Releases**，下载最新的 **Windows x64** 压缩包
   （选名字里**不带 `lite`** 的那个完整包，自带运行环境；带 `lite` 的需要你本机已装 Node 22.13+）。
2. 解压，得到一个文件夹（里面能看到 `node.exe`、`index.mjs`）。
3. **把这个文件夹改名为 `snowluma`**（名字必须是这个）。
4. 放到程序目录下，和 `QQ聊天机器人.exe`、`node.exe` **同一层**：

   ```
   qq-bot\
   ├─ QQ聊天机器人.exe
   ├─ node.exe
   ├─ snowluma\          ← 就是这里
   │  ├─ index.mjs
   │  └─ node.exe
   ```

5. 放好后，面板「启动与状态」页里那条「还差一步：装 QQ 网关」的提示会自动消失。

> 如果你已经用别的方式让 SnowLuma 在跑（比如旧版本装在别处、38001 端口能连），
> 本程序会直接复用它，不一定非要放在目录里。

### 1. 一个 QQ 号（建议用小号）

- 机器人要登录 QQ，**不要用你的主号**（有风控风险，也可能被临时限制）。
- 注册：手机 QQ 或 <https://new.qq.com/>。
- 建议：新号先正常用几天、加几个好友，别一注册就挂机器人。

### 2. 一个模型 API Key（必须）

机器人靠它说话。任选一家，只要是 **OpenAI 兼容接口**：

| 服务商 | Base URL 填什么 | 在哪拿 Key |
| --- | --- | --- |
| DeepSeek 官方 | `https://api.deepseek.com/v1` | <https://platform.deepseek.com/> → 左侧「API keys」→ 创建 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | <https://cloud.siliconflow.cn/> → 「API 密钥」 |
| 其他中转 | 服务商给的地址 | 服务商后台 |

- **模型名**：DeepSeek 常用 `deepseek-chat`；硅基流动常用 `Qwen/Qwen2.5-72B-Instruct` 之类。
  不确定就点面板上的「**获取可用模型**」，它会直接向接口要一份列表。
- 计费：按 token 收费，日常聊天一天几毛到几块。新账号一般有赠送额度。

### 3. 网关 Token（**通常不用你填**）

- 先按[准备工作第 0 步](#0-下载-qq-网关必须两分钟)把网关装进程序目录。它第一次启动后会在
  `snowluma\config\onebot_<你的QQ号>.json` 里生成 `token`，程序会自动读、自动试，
  **正常情况下面板里显示「QQ 已在线」即可，不用手填**。
- 如果显示未连接、要手动找：用记事本打开
  `snowluma\config\onebot_<你的QQ号>.json`，找 `token` 字段，复制到面板「模型与密钥 → 网关接入 → accessToken」。

### 4.（可选）语音

- Fish Audio：<https://fish.audio/> → 右上角头像 →「API Key」。
- 填到面板「语音合成 → apiKey」。**没有音色的角色不会发语音**，只打字。

### 5.（可选）联网搜索

- 用同一个 DeepSeek Key 就行（面板里 `apiKeyEnv` 填 `DEEPSEEK_API_KEY`，或者直接把 key 填进 apiKey）。
- 不填也能用，只是机器人不能查最新消息。

## 快速开始（从解压到聊起来）

### 第 1 步：解压

把压缩包解压到一个**路径短、没有中文和空格**的目录，例如 `D:\qq-bot\`。

> 不要放在 C 盘用户目录、桌面、OneDrive 同步目录里——容易出权限和路径问题。

**顺手把网关放进去**：按[准备工作第 0 步](#0-下载-qq-网关必须两分钟)，把解压出来的文件夹改名为 `snowluma`，
放到刚才解压的目录里（和 `QQ聊天机器人.exe` 同级）。这一步忘了也能先启动，面板会提示你补。

### 第 2 步：双击 `QQ聊天机器人.exe`

- 会弹出一个「QQ 聊天机器人控制台」窗口（第一次可能要等 5～10 秒）。
- 如果没反应：看 `state\ui.log`；或者双击 `start.bat`（带黑窗口，能看到报错）。

### 第 3 步：填模型配置

左侧「**模型与密钥**」：

1. 「语言模型」：Base URL、模型名、API Key 三格填上（见上一节）。
2. 点「**获取可用模型**」验证能不能连通（能列出模型就说明 Key 和地址都对）。
3. 「网关接入」一般不用动（默认 `ws://127.0.0.1:38001` / `http://127.0.0.1:38000`）。
4. 点页面下方「**保存配置**」。

### 第 4 步：填对话范围

左侧「**对话范围**」：

- **群号**：机器人要进的群（多个用换行或逗号分隔）。
  拿群号：QQ 群 → 群设置 → 群号，或者在群里 @ 机器人后看日志。
- **好友 QQ**：允许私聊的 QQ 号（可以留空，只用群）。
- **管理员 QQ**：你自己的 QQ，静默时段里管理员 @ 也算例外，必填。
- 控制台端口（3101）和控制台令牌一般不用改——令牌会自动生成，面板自己带着。
- 点「**保存配置**」。

### 第 5 步：启动

回到「**启动与状态**」页：多数情况下面板已经自动把网关和机器人拉起来了，直接看状态即可；没起来再点对应那行的「启动」。

1. 网关启动：5099（WebUI）、38000（HTTP）、38001（WebSocket）三个都变绿。
2. 机器人启动：3101 变绿。
3. 状态卡显示「待命 / 潜水」之类，就说明活了。

### 第 6 步：登录 QQ（扫码）

- 在「启动与状态」页点网关那行的「**登录页**」（或自己开 <http://127.0.0.1:5099/>）。
- 在网关页面里登录 QQ 账号：按提示扫码 / 密码登录。
- 登录成功后回到面板：网关那行会显示「QQ 已在线」，最上面那张状态卡会显示「待命」或「潜水」。

### 第 7 步：把它拉进群，@ 它

- 用你的主号把**机器人号**（就是你刚才扫码登录的那个 QQ）拉进群，或者先私聊测试。
- 群里 `@机器人 在吗`，等几秒，它应该按角色设定回复。
- 私聊直接发消息即可（前提是该 QQ 在「好友 QQ」白名单里）。

### 第 8 步：调教成你想要的样子

- 「**角色与行为 → 人格与角色**」：换角色。
- 「**角色包**」：给角色配音色、别名、注音、世界观名。
- 「**静默时间**」：设置它什么时候不主动说话。
- 「**关窗行为**」：关掉窗口后是继续在后台跑，还是一起停掉。

## 面板字段对照表

### 模型与密钥

| 字段 | 填什么 | 备注 |
| --- | --- | --- |
| 语言模型 Base URL | `https://api.deepseek.com/v1` 等 | 末尾带 `/v1` |
| 语言模型 模型名 | `deepseek-chat` 等 | 可点「获取可用模型」挑 |
| 语言模型 API Key | `sk-...` | 只存在本机 `config.json` |
| 语音合成 apiKey | Fish Audio 的 key | 可选；不填就不发语音 |
| 语音合成 模型 | `s2.1-pro-free` 等 | 默认即可 |
| 联网搜索 apiKey | 复用模型 key 或搜索服务 key | 可选 |
| 网关 wsUrl / httpUrl | `ws://127.0.0.1:38001` / `http://127.0.0.1:38000` | 一般不用改 |
| 网关 accessToken | 自动发现，一般留空 | 见「准备工作」第 3 条 |

### 对话范围

| 字段 | 填什么 | 备注 |
| --- | --- | --- |
| 群号 | 允许机器人说话的群 | 不在白名单的群一律忽略 |
| 好友 QQ | 允许私聊的人 | 留空 = 不开私聊 |
| 管理员 QQ | 你自己的号 | 必填 |
| 控制台端口 | 默认 3101 | 和别的程序冲突时改 |
| 控制台令牌 | 自动生成 | 存 `state\console-token` |

## 日常操作

**换角色**：左侧「人格与角色」→ 选一个 → 保存配置。角色卡是 `roles\<名字>.md`。

**配角色包**：左侧「角色包」→ 选角色 → 填音色 ID / 别名 / 注音字典 / 世界观名 → 「保存角色包」。
有角色包的 `<角色>.pack.json` 存在 `roles\` 里；没有音色的角色不会发语音。

**改静默时间**：左侧「静默时间」→ 工作日、周末与法定节假日分别加时间段 → 「保存并立即生效」。
留空 = 这一天全天都正常（不静默）。

**改用 DSH 后端（可选，一般用不上）**：左侧「模型与密钥 → 后端」选「连 DeepSeek Harness」，
点「检测 DSH 端口」自动扫出地址（DSH 每次启动都会换随机端口），再点「保存配置」重启机器人。
不选这一项时机器人自己直连模型 API，完全不需要 DSH。

**看日志**：左侧「启动与状态」底部有「桥接日志 / 网关日志 / 面板日志」三个按钮，启动过程也在这里看；或直接看 `state\bridge.log`（机器人）、`state\ui.log`（面板）。
> 双击 `QQ聊天机器人.exe` 或 `start.bat` 都不会留下黑窗口，所有输出都在面板日志里。


**关窗行为**：左侧「关窗行为」→ 选「继续在后台运行」或「一并停止机器人和网关」，会记住。

**彻底退出**：面板里点「停止机器人」+「停止网关」，然后关窗口；或者直接关窗口（如果选了「一并停止」）。

## 常见问题

**双击 exe 没反应？**
看 `state\ui.log`；或改双击 `start.bat`，它会留一个黑窗口显示错误。

**提示端口被占用？**
3199 / 3101 / 5099 / 38000 / 38001 有冲突。关掉重复启动的副本，或者改 `config.json` 里的 `consolePort`。

**面板打不开 / 一直转圈？**
面板只监听 `127.0.0.1:3199`，确认没有别的程序占用；用浏览器直接开 <http://127.0.0.1:3199/>。

**扫码登录后掉线？**
QQ 风控。换小号、降低发言频率、关掉「主动搭话」，第二天再试。

**机器人不说话？**
1. 看状态卡：是不是「静默中」；
2. 看日志有没有 `工具统一发送`；
3. 确认群号/好友号在白名单里；
4. 模型 Key 是否余额不足（面板「令牌与花费」）。

**没有语音？**
1. 当前角色有没有角色包音色（「角色包」页看）；
2. Fish Audio key 是否填了、余额是否够；
3. 合成超时会自动退回纯文字。

**面板说「还差一步：装 QQ 网关」？**
这个目录里没有 `snowluma\`。按[准备工作第 0 步](#0-下载-qq-网关必须两分钟)下载、改名、放进去，回面板刷新即可。

**改了 config.json 要重启吗？**
大部分要；面板里改的会自动生效（面板写的是同一份 config.json 并通知机器人）。
