## 3. 已做功能（按模块）

### 3.1 静默时段
- `src/quiet-hours.mjs`，状态机 normal / quiet / override（临时恢复 15 分钟）。
- 规则：分「工作日」和「周末与法定节假日」两套时段，各配各的；哪几天算工作日可配，法定节假日自动排除，调休补班日算工作日；某一套留空 = 当天不静默。默认工作日 09:00–12:00、14:00–18:00，周末与法定节假日留空。
- 静默期间丢弃唤醒，**管理员 QQ（ownerQQ）主动 @ 例外**。
- 控制台「静默」卡片 + 覆盖按钮；时段在面板「角色与行为 → 静默时间」页配置，保存即时生效。

### 3.2 Fish Audio TTS
- `src/tts-fish.mjs`：`POST {baseUrl}/v1/tts`，headers `Authorization: Bearer + model: s2.1-pro-free`，body `{text, reference_id, format:"mp3"}`。
- 错误码：no-key / empty-text / no-voice / timeout / network / auth / rate / server / bad-response / empty-audio / too-long。
- 发送方式是 `record` segment + 本地文件路径（SnowLuma 自带 `native/ffmpeg`）。
- 输出约定：**只念日语，紧接着发一条文字版「日语 + 中文字幕」**。
- `maxSeconds: 60`；字数 > maxSeconds×8 直接返回 too-long，不做真合成。
- 注音字典在角色包的 `dictionary`（kana 音素串，如 `透です → to0o1ru1de1su0`）。
- 端点：`/api/tts/config`、`/api/tts/preview`、`/api/socialV2/tts-say`；MCP 工具 `qq_tts_say`。
- 三条触发并存：@她说句话 / 控制台按钮 / AI 自己判断。
- 情绪标签：Fish S2 支持 `[calm]` `[relaxed]` `[resigned]` `[bored]` `[soft tone]` 等，但**当前不自动加**（用户判断情绪偏高是音色本身问题，决定不改）。

### 3.3 角色包（多角色）
- 目录：`roles/<角色名>.md` + `roles/<角色名>.pack.json`，资料放 `roles/.refs/`，备份 `roles/.backup/`。
- pack 字段：`roleFile` / `voiceId` / `dictionary` / `aliases` / `ttsEmotionPrefix` / `worldName`。
- 现有三张：`七草日花`（原角色）、`浅仓透`、`七草はづき`（事务员，无歌/演出）。
- 切角色连带换：角色卡 / TTS 音色 / 注音字典 / 唤醒别名 / 世界观；**不清软记忆**。
- 控制台「角色」下拉 + 显示「当前音色 · 世界观 N 字（N 首 / N 场）」。
- 别名：日花 组 = 日花/にちか/七草/七草日花；透 = 浅仓透/浅仓/とおる/あさくら/透；はづき = 七草叶月/叶月/はづき/七草はづき/はづきさん。

### 3.4 世界观（eidolon world.json）
- `src/world-prompt.mjs`：三段生成（世界设定 754 字全带 + 歌只留歌名 + 演出只留名字和年份），A 档。
- `world.json`（1.3MB）从 eidolon 复制到项目根目录，**不进 git**。
- 注入点是 `qq_get_prompt` 的返回值（跟角色卡同路，切角色即时变，进历史走缓存）。
- 切角色时重置 `bootstrapSent`，强制模型重走一次引导唤醒（它会照做，实测稳定）。
- 静态化（不含 today 变量），让前缀命中缓存；实测 cacheMiss 305 / cacheHit 388352。

### 3.5 主动搭话（eidolon reach_outs）
- `scheduleProactiveCheckV2` 按会话跑（`group:xxx` / `private:xxx`），所以群发/私发天然区分。
- 参数见第 2 节；夜间是**硬禁止**（23:30 判到分钟，落在窗口内推到 07:00 后 0–2 小时）。
- 提示词结构：【主动机会】+【由头优先级：先接旧话题，热点第二】+【反重复开头】+【只说自己日常，不编剧情】+【实在没话】。
- 控制台卡片在「运行总览」页，「DSH 模型与思考强度」下面；social-v2 页的重复入口已删。

### 3.6 DSH 模型跟随
- 控制台以前读 `config.json` 写死的 provider/model，跟 DSH 实际用的不一致（`sessions.selectModel` 名义成功实际空转）。
- 现在 `readDshDefaultModel()`（`bridge.js:2603`）+ `readLastUsageModel()`（`bridge.js:2655`）双模式，`ensureChatModel`（`bridge.js:8528`）跟随 DSH。
- 真实默认模型来源：`C:\Users\Nis\.dsh\profiles\desktop\cordis.patch.yml` 的 `agent-default-model`。
- 用户后来把 DSH 默认切回 `deepseek-account / deepseek-flash`。

### 3.7 黑话 / 梗
- 黑话库 138 条；导入过 `偶像大师黑话与Meme.md`（91 条）+ `淫梦Meme词条.md`。
- 匹配：精确子串 → 去标点变体 → 长度≥4 允许 1 字符差；2–3 字只走精确（防误触）。
- 注入：唤醒时最多 3 条；`matchWindow=15` 条消息窗口；另外在 `qq_wait_for_messages` / `qq_get_unread_messages` / `qq_get_recent_messages` 的返回里附 `slangHint`（解决"会话繁忙暂存导致用旧 prompt"的漏注入）。
- 日志：`[slang] 命中 N 条，注入本轮唤醒：…` / `附在读取结果里：…`。

## 4. 踩过的坑（别重犯）

| 现象 | 根因 | 处理 |
|---|---|---|
| `unknown prompt variable "{{cwd}}"` | preset 不支持该变量 | 删掉，只用 provider/model |
| `session/model-unavailable` | provider 写成 deepseek 而非 deepseek-account | 改 provider |
| SnowLuma `listen EACCES` 3000/3001 | Windows 动态端口保留段 2934-3033 | 改 38000/38001 |
| bat 启动错乱、`/nobreak` 变 `eak` | 文件存成 LF+UTF-8 | bat 必须 CRLF + GBK |
| launcher.bat 找不到路径 | 它不自己 cd | `start "" /d "<dir>" launcher.bat` |
| 「七草はづき」被截成「七草」 | `sanitizeRoleName()` 正则不含假名（`bridge.js:710`） | 正则加 `\u3040-\u30ff\uFF66-\uFF9D` |
| 切角色后音色没变 / 旧音色写进新卡 | 控制台只刷人格卡没刷音色框（`console.html:3163`） | 加 `loadTtsConfig(true)` |
| 「透发出叶月的声音」 | 我用 API 改了角色，页面仍显示旧角色 | 页面和后端要同时刷 |
| AI 输出文本但没进 QQ | reserved2 不自动转发，它没调发送工具 | 换模型或加兜底（未做） |
| 唤醒失败 `does not support reasoning effort "max"` | DSH 默认 grok-4.5 无 effort，桥接拿内置 max 补 | 跟随模式不猜 effort，失败去掉 effort 重试 |
| 卡片重叠 | CSS grid 强制 `.row` 同格 | 已修 |
| 黑话漏注入 | 会话繁忙 → 暂存 → 没重新生成 prompt | 读取类工具返回里补 `slangHint` |
| 中文写入管道报 `'gbk' codec` | Windows 控制台编码 | Python 写 UTF-8 文件再读 |
